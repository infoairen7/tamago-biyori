# 採点バージョン 2.0.0：油・差し水・縁の焼き目

目玉焼きの奥深さをゲームに取り入れるため、設計1.0（02_GAME_UX_SPEC.md）のモデルに次の4つを加えました。
**はじめの1皿（サラダ油・ふつう・差し水なし・縁「ほんのり」）では設計1.0とまったく同じ計算**になり、仕様書の確認表（白い卵・とろり・中火で約27.6秒に100点など）もそのまま成り立ちます。

これはゲーム用の簡易モデルです。実際の調理温度・時間・安全性、油や卵の品質の良し悪しを表すものではありません。

## 1. 追加した選択肢と操作

| 要素 | 選べるもの | 解放 | 効き方（ゲーム内） |
|---|---|---|---|
| 縁の焼き目（目標） | しろく／ほんのり／カリッと | 1皿焼いたあと | 採点の「焼き目20点」の目標が変わる |
| 油の量 | 少なめ／ふつう／たっぷり | 1皿焼いたあと | 焼き色の進みやすさと焦げやすさ |
| 差し水（操作） | 調理中に1回だけ（キー W） | 2皿焼いたあと | 熱が下がり蒸気が立つ。ふたと合わせると蒸し焼き |
| 油の種類 | サラダ油／バター／ごま油 | 3皿焼いたあと | 色づき始める温度・色づきやすさ・焦げ始める温度 |

設定の「こだわりをすべて使えるようにする」で、解放を待たずに全部選べます。まだ解放していない項目は基本の値で焼きます。

## 2. モデルの追加（`shared/model.ts`、係数は `config/game-config.json`）

状態に S（差し水の蒸気 0〜1）、F（黄身の白い膜、見た目のみ）、wet（白身の水っぽさ）、waterStep を追加しました。

```text
steam = S × (ふた閉 ? 1 : 0.25)
T = 前と同じ（差し水の瞬間だけ T −= 0.15）
W += dt·egg·0.055·T·(1+0.18·lid)·(1 + 0.6·steam)
Y += dt·egg·0.019·T·(1+0.70·lid)·(1 + 2.2·steam)
B += dt·egg·0.020·油.色づき·量.色づき·max(0,(T−油.色づき温度)/(1−油.色づき温度))·(1−0.4·lid)·(1 − 0.9·S)   ※oldW≥0.55
D += dt·egg·0.028·量.焦げ·max(0,(T−油.焦げ温度)/0.22)·(1 − 0.95·S)                                          ※oldW≥0.60
S −= dt·(0.03 + 0.16·T)·(ふた開 ? 2.5 : 1)
差し水の瞬間：wet = max(0, (0.45 − W) / 0.45)   … 白身が生のうちに差すほど水っぽい
```

| 油 | 色づき | 色づき温度 | 焦げ温度 | ひとこと |
|---|---|---|---|---|
| サラダ油 | 1.0 | 0.35 | 0.78 | 設計1.0と同じ。中火では焦げない |
| バター | 1.5 | 0.22 | 0.60 | 弱火でも色づく。中火でも少しずつ焦げる |
| ごま油 | 1.2 | 0.32 | 0.70 | その間 |

| 油の量 | 色づき | 焦げ |
|---|---|---|
| 少なめ | 0.7 | 1.4 |
| ふつう | 1.0 | 1.0 |
| たっぷり | 1.5 | 0.7 |

## 3. 採点

白身40＋黄身40＋焼き目20の枠組みは同じです。焼き目の目標だけが縁の選択で変わります。

| 縁 | 目標B | 許容幅 | 減り方 |
|---|---|---|---|
| しろく | 0.00 | 0.07 | 0.30 |
| ほんのり | 0.22 | 0.12 | 0.60（設計1.0と同じ） |
| カリッと | 0.45 | 0.10 | 0.40 |

```text
raw = 基礎点 × (1 − 0.9·D) × (1 − 0.3·wet)   → 生の白身39点・強い焦げ49点の上限は同じ
```

結果画面では「基礎点 → 焦げ −x → 水っぽさ −y → 上限 → 最終点」を別々に表示し、失点の原因と選んだ道具に合わせて次の一手を示します（例：カリッとが足りない→「油をたっぷりにすると、縁がカリッとしやすい」）。

## 4. 確認した調整結果（`npm run simulate` / `npm test`）

- 卵3種 × 黄身3種 × 縁3種の **全27条件で100点**を取れる手順がある。
- 基本の道具だけでも縁「ほんのり」の9条件は全て90点以上（設計1.0と同じ）。
- **「とろり × カリッと」は基本の道具だけでは最高92点**。ごま油たっぷり（中火36.7秒）やバターたっぷり（強火10秒→弱火）で100点に届く。
- 差し水は「速さ」と「仕上がりの幅」を生む。例：白い卵・しっかり × 縁カリッと は中火のまま66秒かかるところ、ごま油たっぷりで30秒焼いてから差し水＋ふたにすると45秒で100点。しっかり × しろく も弱火＋ふたの66秒に対し、少なめ・中火→差し水＋ふた→弱火で48秒。
- 差し水を早く（白身がまだ透明なうち）すると水っぽさの減点が入る。
- 強火で90秒放置すると4点（焦げ）。

より広く手順を探す総当たりは `npm run tune`（数分）。

## 5. ランキングとデータ

- ランキングの区分は **採点バージョン × 卵 × 黄身 × 縁 × 期間**。油は区分に含めず「腕の見せどころ」として、各行に「油・量／差し水の秒／お皿へうつした秒」を表示します。
- `POST /api/runs` は `edgeId`・`oilId`・`oilAmountId` を受け取り、サーバーはrun発行時の値で再計算します（完了時の送信内容では変えられません）。
- 操作ログに `{"action":"water","value":"add"}` が加わりました（1回まで。2回あれば拒否）。
- 採点バージョンが変わったため、1.0.0の記録は2.0.0のランキングに混ざりません。既存のSQLiteは起動時に列を自動で追加します。
