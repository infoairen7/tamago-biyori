# デザイン・素材ガイド

## アートディレクション

暖かな朝のキッチン。クリーム、セージグリーン、黄身のオレンジ、黒い小型パンを軸にする。食材は少しリアルで、形と環境はシンプル。料理のつやと余白を主役にし、キャラクターや派手なエフェクトは必須にしない。

透過PNGの輪郭は元画像を維持。小サイズ化やWebP化はClaude実装時に別ファイルとして行う。元PNGを破壊しない。

## 3D制作プロンプト（Claudeに渡す）

```text
添付のhero.pngを、朝の光と食材の質感の参考にしてください。
Three.jsの標準的なgeometryとmaterialで、以下の3Dシーンを制作してください。
カメラは料理人の目線から約50度下向き。操作による歩行や自由旋回なし。
白身と黄身が常に大きく見える構図。パンの柄は画面右下へ。

1. 直径約18cmを想起させる小型の黒い目玉焼き専用フライパン。
   外周・内側・底の段差と木の柄を別形状にし、金属は微細な粗さ。
2. 卵殻は少し先が細い卵型メッシュ。白/赤/うずらの色と斑点を設定から変更。
   2つの殻の半分を左右へ開き、割る動作を0.8秒程度で見せる。
3. 白身は不規則な外周の薄いmesh。Wで透明→不透明へ変化。
   Yで黄身のroughness・色・揺れを変化。黄身はつぶれた半球形。
   Bで縁を黄金色、Dで縁から焦げを表現。形状はseedから決定。
4. ふたは持ち手付きの丸い透明ガラス。閉じても卵が読める。
   透明描画が重い環境では簡略化して、観察ラベルを併用。
5. 木のカウンター、淡いタイル、白い皿、調理器を最小限の形状で構成。
6. 左上から暖かな主光、柔らかな環境光。パンの接地影を入れる。
7. 泡と湯気は少数の軽量パーティクル。減速や画質設定で数を落とす。
8. 結果では同じ卵meshと材質状態を皿へ移す。イラストへの置き換えはしない。

重い物理エンジン、流体シミュレーション、動的反射、外部モデルを必須にしない。
卵の落下・広がりは短い補間アニメーションで表現してください。
```

## 2D切り替え時の制作プロンプト

```text
WebGL 2が使えない環境では、同じGameModelを読むCanvas 2D rendererに切り替える。
楕円のパン、木の柄、不規則な白身、グラデーションの黄身、焼き色リング、湯気を描く。
W/Y/B/Dとseedを3Dと共有し、見た目・入力・採点・画像保存の意味を揃える。
パースと明暗で奥行きを表現し、画面に「軽量表示」を小さく示す。
2Dでも全ての操作とランキング条件を維持し、低画質だから点数を下げない。
```

## 音の制作指示

音源ファイルは今回の同梱対象外。ClaudeではまずWeb Audio等による簡易音、または無音でも動作する構成にする。後から以下のオリジナル効果音へ差し替えられるようにする。

| 音ID | 制作プロンプト・要件 |
|---|---|
| egg_tap | 卵殻を軽く一度たたく乾いた小さな音、0.15秒、余韻なし |
| egg_crack | 卵の殻がぱきっと開く自然な音、0.5秒、破壊音を誇張しない |
| egg_drop | 卵が温かい小型フライパンへ落ちる柔らかな音、0.7秒 |
| sizzle_loop | 目玉焼きがじゅわじゅわ焼ける細かな油の音、4秒ループ、声・音楽なし、接続点が目立たない |
| lid_on/off | ガラスぶたが金属パンへ軽く触れる音、0.4秒、耳障りにしない |
| plate | 目玉焼きが皿へ滑る柔らかな音、0.6秒 |
| result_good | 朝らしい軽い木琴の3音、0.8秒、成功を明るく知らせる |

焼ける音量はTと進行に連動。ふたをすると少しこもる。失敗時に大音量のブザーを鳴らさない。BGMは必須にせず、焼ける音を主役にする。配布する音素材の利用条件は実装時に確認する。

## UIトークンと部品

正確な値はdesign-tokens.jsonを参照。背景#FFF8EB、深緑#244C3A、文字#28392D、黄身色#F5B42A。黄身色上の文字は濃色。淡い黄色の上に白文字を置かない。

角丸16〜20px、余白8の倍数を中心に4/12も使用。本文16px、補助14px、見出し24〜32px、点数64px。タッチ対象48px以上。フォントは日本語システムフォントを基本に、外部フォント通信を必須にしない。

必要部品：PrimaryButton、SecondaryButton、IconButton、EggCard、TargetSegment、HeatSelector、LidToggle、CookingStatus、ScoreBreakdown、ShareActions、RankRow、SponsorCard、Toast、PauseDialog、EmptyState。

各部品は通常/押下/選択/フォーカス/無効/読込中を持つ。ランキングの空/通信失敗、PNG準備中、共有キャンセルは別状態にする。

## 画面見本の読み方

UI_DESIGN.htmlは画面設計を確認するためのHTMLです。ゲーム機能や外部送信は実装していません。調理画面に置いたhero.pngは合成見本であり、本番では動く3Dへ置き換えます。

デザイン見本の96点、名前、順位、PR枠はサンプル表示です。最終結果の食品状態・採点内容・公開ランキングは実データから表示してください。
