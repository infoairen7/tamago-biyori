# たまご日和 — Claudeへの渡し方

「じゅわっ、とろっ。今日のひと皿。」

スマートフォンを中心に、PC・タブレットでも遊べる主観視点の目玉焼きゲームの制作資料です。ゲーム本体はまだ実装していません。仮タイトル、架空の卵カード、協賛企業の差し替え枠を使っています。

## 最初に見るもの

1. `UI_DESIGN.html` をブラウザで開く：スマートフォン6画面、PC画面、配色と部品の見本。
2. `UI_OVERVIEW.png`：スマートフォン6画面をまとめた確認画像。
3. `CLAUDE_COMPLETE_PROMPT.md`：必要な仕様と設定を1つにまとめたClaude用の制作プロンプト。全文をコピーできます。

## Claudeへの渡し方

ZIPを展開し、まず `CLAUDE_COMPLETE_PROMPT.md` と `UI_OVERVIEW.png` を添付してください。画像素材を使う段階で `assets` 内のPNG4点も添付します。ファイルが多い場合は段階ごとに分けて渡せます。

最初に送る文章：

> 添付の「たまご日和」の制作指示書に従い、主観視点の3D目玉焼きゲームを実装してください。まず段階1の遊べるローカル版を完成させ、続いてX共有、公開ランキング、企業PR導線を実装してください。UIは添付の画面デザインを参考にし、採点仕様は02_GAME_UX_SPEC.mdを正としてください。ゲームの計算は描画から分離し、3Dが使えない端末では2D描画へ切り替えてください。未接続のランキングを実データに見せないでください。説明だけで終わらず、必要なソースコード、起動手順、検証結果を出してください。

## 公開前に埋める項目

- 協賛企業名、使用許諾のあるロゴと商品画像、商品説明、購入先URL。
- 公開先URL、ランキングのサーバー・データベース接続先。
- 実際に検証する端末とブラウザ、計測方法、公開ランキングの運営担当。

主要な現行ブラウザを目標とし、古い端末や特殊なアプリ内ブラウザも含む「全環境の完全保証」はしません。3D→2Dの切り替え、共有画像保存、通信失敗時の継続で遊べる範囲を広げます。

デザイン画像の96点やランキング名は表示見本です。画像素材は実在商品の写真ではなく生成イラストです。実際の焼き上がりはプレイ結果から描画し、見本の写真を結果として流用しないでください。
